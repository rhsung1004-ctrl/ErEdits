# ERKillCut — 이터널리턴 킬 하이라이트 자동 컷 편집기

**⬇ 다운로드 (Windows):** [최신 버전 ERKillCut-windows-x64.zip](https://github.com/rhsung1004-ctrl/ErEdits/releases/latest/download/ERKillCut-windows-x64.zip)

방송 다시보기를 넣으면 **킬 장면만 남기고 나머지를 자동으로 잘라** 16:9 영상 한 편으로 만들어 주는 Windows 프로그램입니다.
킬 감지는 [ERShorts](https://github.com/rhsung1004-ctrl/ershorts)와 같은 방식(화면 오른쪽 위 TK·K·A 숫자 변화)을 씁니다.

## 사용 순서
1. **방송 다시보기 열기** (mp4 · mkv · ts · flv … / 창에 끌어 놓아도 됨)
   한 방송이 **여러 파일로 나뉘어 있으면 함께 고르세요** — 순서를 확인한 뒤 하나의 영상처럼 이어 붙여 분석·재생·내보내기
   (타임라인에 파일 경계가 점선으로 보임, 같은 파일들을 다시 고르면 이전 분석·편집이 그대로 열림, 해상도가 같은 파일끼리만).
2. **영역 지정** — 방송 화면에서 TK·K·A 숫자 줄에 상자를 맞춤. 확대 화면에 숫자 3개가 초록 상자로 잡히면 성공.
   웹캠·채팅 오버레이로 게임 화면 위치가 다른 스트리머도 상자만 옮기면 됨. **스트리머별 프리셋**으로 저장해 두면 다음부터 그대로 사용.
3. **킬 찾기 시작** — 정확하게(초당 5장) / 빠르게(키프레임만, 킬 시각 ±2초). 분석 결과는 영상별로 자동 저장돼서 다시 열어도 그대로.
   분석이 끝나면 **킬 숫자 확인**: 킬마다 전·후 화면의 TK·K·A 숫자를 직접 읽어 K가 실제로 올라갔는지 봄.
   숫자 모양만 바뀌고 값은 그대로인 "잘못 잡힌 킬"은 클립에서 빠지고, A만 올라간 건 어시스트로 고침 (이전에 분석한 영상은 [킬 숫자 다시 확인]).
4. **클립 확인** — 킬 몇 초 전~후, **연속 킬 묶기**(기본 20초: 킬·어시 뒤 20초 안에 다음 킬·어시가 나오면 한 클립으로 이어 붙임), 어시스트 포함 여부.
   클립 더블클릭으로 미리보기, 시작/끝 ±1초 · 현재 위치로 맞추기, 클립 끄기/삭제, 놓친 장면 직접 추가.
   **편집 타임라인** (미리보기 아래): 결과 영상 순서대로 클립을 장면 썸네일·킬 표시와 함께 보여 줌.
   클릭으로 이동, 선택한 클립 양 끝을 끌어 길이 조절, **Ctrl+X** 재생 위치에서 자르기, **Delete** 클립 삭제, **Ctrl+Z / Ctrl+Y** 되돌리기,
   Ctrl+휠 확대. "결과만 이어서 재생"을 켜면 잘린 부분을 건너뛰고 결과 영상처럼 재생.
5. **판 등수** (판 등수 탭) — 킬 찾기를 하면서 게임이 끝난 뒤의 **결과 화면 · 점수 창 · 순위표**도 함께 찾아 판마다 등수를 읽음.
   **"3등 이상 판의 킬만 남기기"**처럼 등수 필터를 켜면 그 판의 킬만 클립이 됨 (등수는 1~24, 기본 3등).
   두 화면 이상에서 같은 등수면 *확실*, 한 화면만 읽었거나 서로 다르면 *확인 필요*. 판마다 남김 체크·등수(더블클릭)를 직접 고칠 수 있고,
   판별 기록을 CSV로 저장. 방송인이 결과 화면을 1초 만에 넘겨도 판마다 화면이 2~3개라 대부분 잡힘 (**정확하게** 분석 방식 권장).
   게임 화면이 방송 화면 일부에만 들어간 스트리머는 [게임 화면]을 "킬 숫자 영역으로 계산"으로.
6. **AI 편집점** (AI 편집점 탭) — 채팅 반응 + 소리 크기 + 게임 신호로 편집점을 잡음.
   - **화면 채팅 (기본)**: 킬 찾기(정확하게)를 할 때 방송 화면 오른쪽 채팅창도 같이 봐서, 채팅창이 밀려 올라가는 속도로 채팅이 몰린 순간을 잼.
     채팅창 위치가 다르면 [채팅창 영역 지정]으로 한 번 맞춤. 이미 분석한 영상은 [화면 채팅만 분석].
   - (선택) 치지직 다시보기 주소로 채팅을 받으면 ㅋㅋ 같은 내용까지 봐서 재밌는 장면이 더 정확함 (받은 채팅이 있으면 그걸 먼저 씀).
   - **잘한 장면**: 킬 클립마다 ★점수 (킬 수 · 몰아서 킨 킬 · 채팅 폭발 · 큰 리액션 · 1등 마지막 교전). [점수 높은 클립으로 맞추기]로 롱폼 길이에 맞춰 켜고 끄기.
   - **재밌는 장면**: 킬이 없는 곳에서 채팅이 확 몰린 순간을 후보로. [환기용 자동 넣기]로 결과 영상 몇 분마다 하나씩 넣음 (초록색 클립).
   - **로컬 AI로 확인** (선택): whisper.cpp 로 후보 앞뒤 방송인 말을 받아 적고, Ollama(기본 `qwen3:8b`)가 재밌는 장면인지·시작/끝·한 줄 설명을 정함.
     [AI 설정]에서 `whisper-cli.exe`·모델(`ggml-large-v3-turbo-q5_0.bin` 추천)·Ollama 모델을 지정. 영상·채팅은 컴퓨터 밖으로 나가지 않음.
7. **자막** (자막 탭) — 재생 위치에 자막 넣기, 여러 줄, 길이·시작/끝 맞추기, 글꼴·크기·글자색·테두리(색/두께)·그림자·반투명 박스·부드럽게 나타나기,
   세로 위치(미리보기에서 자막을 직접 끌어도 됨), "이 모양을 모든 자막에 적용". 마지막에 쓴 모양이 다음 자막의 기본값.
   **글꼴 추가**: TTF/OTF 파일을 골라 추가하면 `%APPDATA%\ERKillCut\fonts`에 복사돼 계속 사용 (미리보기와 결과가 같은 글꼴 파일 사용).
   **스킬 콤보 색**: `Q-F-W-E-R-E-D` 처럼 키를 `-`로 이어 쓰면 키마다 색이 자동으로 바뀜 (기본: QWERD 연한 주황, F 하늘색, `-` 흰색).
   [색 설정…]에서 캐릭터별 프리셋을 만들어 키·색·`-` 색을 바꾸고, 자막마다 프리셋을 고름. 키 하나만 있거나 일반 문장은 그대로.
   자막은 원본 시간 기준으로 저장돼서 클립 길이를 바꿔도 그 장면에 붙어 있음. 사용 클립 밖 자막은 목록에 회색으로 표시.
8. **영상 내보내기** (3. 내보내기 탭, [영상 내보내기] 버튼은 어느 탭에서든) — 클립 사이 **크로스페이드**, 영상 처음 **페이드 인** / 끝 **페이드 아웃** (소리도 함께),
   **소리 크기 맞추기**(유튜브 기준 -14 LUFS, 기본 켬),
   1080p / 1440p / 720p / 원본 높이, 원본·60·30fps. 그래픽카드 인코더(NVENC → AMF → QSV) 자동 선택, 안 되면 CPU(x264).

## 동작 방식
- 킬 찾기: ffmpeg가 지정 영역만 잘라 160×32 밝기 영상으로 줄여 흘려 보내고, `HudKillWatcher`가 숫자 모양 변화를 봄.
  TK와 K(또는 A)가 3초 안에 함께 바뀌어야 "내가 관여한 킬"로 인정 (팀원 단독 킬 제외). 몇 시간짜리도 메모리에 쌓지 않음.
- 킬 숫자 확인: `KillVerifier`가 킬마다 직전·직후 장면의 숫자 줄을 6배로 키워 꺼내 `readHudCounts`로 TK·K·A 값을 읽음 (붙은 숫자 "12"는 나눠 읽음).
  K·A 둘 다 그대로면 다른 장면으로 한 번 더 읽어 둘 다 같을 때만 뺌. 못 읽으면 원래 판단 유지.
- 판 등수: 킬 찾기와 같은 ffmpeg 한 번에 게임 화면을 320x180 으로도 받아 `ResultWatcher`가 화면 아래 가운데의 파란 버튼([나가기]/[계속하기])이
  보인 구간을 결과 화면 후보로 모음. 분석이 끝나면 `RankReader`가 후보마다 원본 장면 한 장을 1920x1080 으로 꺼내 결과 화면의 큰 파란 숫자,
  점수 창의 "매치 순위: N위", 순위표의 "N위"를 읽음. 숫자는 무료 글꼴 51종 + 실제 게임 화면 숫자 표본과 모양(10x16 칸·구멍 수·비율)을 비교.
  결과 화면 후보가 45초 안에 이어지고 사이에 킬이 없으면 한 판으로 묶고, 결과 화면 사이의 킬을 그 판의 킬로 봄.
- 내보내기: 클립마다 `-ss`로 바로 찾아가 읽고, 필터 그래프 하나로 `xfade` + `acrossfade` + 자막(미리보기와 같은 코드로 그린 PNG를 `overlay`) + `fade`/`afade`를 적용해 한 번에 인코딩.

## 프로젝트 구조
```
src/
  HudKillWatcher.*   킬 숫자 변화 감지 (ERShorts와 같은 코드 + 영역 확인용 probe)
  KillScanner.*      ffmpeg로 영상을 훑어 감지기에 넣음 (정확/빠르게, 하드웨어 디코딩 실패 시 CPU로 재시도)
  Segments.*         킬 시점 → 연속 킬 묶기 + 앞뒤 여유를 붙인 클립
  KillVerifier.*     킬 전·후 TK·K·A 숫자를 읽어 실제 킬인지 확인
  EditTimeline.*     결과 영상 기준 편집 타임라인 (자르기·길이 조절·확대)
  Thumbs.*           편집 타임라인용 장면 썸네일 (클립 구간만 1초 간격)
  JoinedPlayer.*     여러 파일 묶음을 하나의 시간축으로 재생 (파일을 바꿔 가며)
  FrameGrabber.*     여러 시각의 장면을 10장씩 묶어 ffmpeg 한 번에 꺼냄 (킬 확인·등수 읽기)
  Highlights.*       채팅·소리 신호 → 잘한 장면 점수, 재밌는 장면 후보, 분량 맞추기·환기용 고르기
  ChzzkChat.*        치지직 다시보기 채팅 받기 (비공식 웹 API)
  ChatMeter.*        방송 화면 채팅창에서 새 채팅 줄 수 세기 (글줄 위치를 앞 장면과 맞춰 보고 새로 생긴 줄만)
  AudioLevels.*      1초 단위 소리 크기
  LocalAi.*          whisper.cpp + Ollama 로 재밌는 장면 확인
  AiPanel.*          AI 편집점 탭
  ResultScreen.*     결과 화면 버튼 찾기(1단계) + 등수 숫자 읽기(2단계), DigitTemplates.inc = 숫자 모양 표본
  RankReader.*       결과 화면 후보마다 원본 장면을 꺼내 등수 읽기 (ffmpeg)
  Games.*            결과 화면 → 판 목록·등수 투표, 등수 필터로 남길 킬 고르기
  Exporter.*         클립 잘라 붙이기 + 크로스페이드 + 페이드 인/아웃 (ffmpeg 한 번)
  RoiDialog.*        킬 숫자 영역 지정 화면 + 스트리머 프리셋
  TimelineBar.*      원본 전체 타임라인 (클립·킬·자막 표시, 클릭으로 이동)
  Subtitles.*        자막 데이터, 원본 시간 → 결과 시간 변환, 미리보기 그리기
  SubtitlePanel.*    자막 탭 (목록·편집·글꼴 추가)
  ComboColors.*      스킬 콤보 색 프리셋 + 자막 안 콤보 찾기
  ComboDialog.*      캐릭터별 콤보 색 프리셋 편집 화면

  VideoView.*        16:9 미리보기 + 자막 표시·끌어서 위치 조정
```

## exe 만들기
GitHub 저장소에 올리면 `.github/workflows/build-windows.yml`이 Windows 서버에서 빌드해
**ERKillCut-windows-x64.zip**을 만듭니다 (Actions → Artifacts, main 브랜치는 Releases에도 자동 게시).

직접 빌드: Qt 6.8 (Widgets, Multimedia) + CMake + Visual Studio
```
cmake -S . -B build -A x64 -DCMAKE_PREFIX_PATH=<Qt 설치 폴더>/msvc2022_64
cmake --build build --config Release
```
실행 폴더에 `ffmpeg.exe`를 함께 두어야 합니다.
